# MiaoCL 客户端参数管理

在 MOD 面板选择游戏实例后，参数管理读取该实例实际游戏目录下的 `slimefunhelper`、`meteor-client` 与 `baritone/settings.txt`。默认打开运行配置，文件快捷入口、功能列表与完整结构视图共用同一份编辑数据。

- SlimefunHelper：按运行配置文件查看参数。新版桥接另外显示游戏注册的功能入口与真实启用状态；开关修改记录到对应 YAML 路径。`nbt:<codec>:<SNBT>` 格式支持展开复合值，原始文本入口保留。
- Meteor：功能列表显示模块启用状态，设置按模块的真实分组直接展开。连接游戏时通过桥接补全默认参数、枚举选项、说明与数值范围，包含已注册的附加模块。磁盘文件仅保存非默认值，离线时无法据此恢复所有默认参数，页面明确说明这一点。
- 保存：可立即保存并热重载、关闭本启动器启动的所选实例并重启、下次启动生效，或取消修改。开关编辑也遵循所选保存方式。
- 全配置：支持导入、导出、命名快照及配置切换。内部缓存中没有已知运行时加载入口的文件需要重启；桥接会说明具体文件。所有应用保留原有备份、冲突检测与失败回滚机制。

## 使用新版桥接

在 MOD 面板点击“升级配置桥接 MOD”，然后重启该实例一次，连接版本应显示 `1.1.1`。后续受支持的模块开关与参数可以通过“立即保存并在游戏内热重载”应用。安装包仍保留原协议与 Fabric 模组标识，以便升级已有桥接，避免重复安装。

## 本次验证范围

配置测试覆盖延期保存、冲突、导入导出、重启时序、NBT 类型保留、SlimefunHelper 编码参数与 Meteor 开关和具体参数。417 个真实配置文件执行只读往返检查。打包界面在独立测试实例中实际执行数值编辑、模块开关、保存和重新读取，并检查原有控件风格与定制文案。

测试没有改动实际 Minecraft 配置，也没有启动实际游戏；真实客户端热重载与附加插件回调尚需游戏内验证。
