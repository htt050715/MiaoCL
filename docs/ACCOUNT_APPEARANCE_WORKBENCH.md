# 账号外观与参数页面自定义

设置 → 外观 → 账号外观中，可选择“跟随当前账号”或指定已保存的展示账号。展示来源同时用于左上角头像、皮肤小人和运行中的窗口／任务栏图标，不改变进入游戏使用的账号。移除所选展示账号后跟随当前账号；没有账号或材质不可用时使用内置 HT_T 头像和完整皮肤。小人默认关闭。EXE 文件和已有快捷方式保留默认 HT_T 图标。

HT_T 默认头像来源：https://mineskin.eu/avatar/HT_T/32 。完整皮肤来源：https://mineskin.eu/skin/HT_T （2026-10-07 获取）。皮肤与头像均内置，无账号时离线可用。账号材质复用现有账号级皮肤缓存；凭据不进入外观数据或主题。

外观工作台的页面选择器包含“客户端参数”和“模组配置菜单”。“默认配置”中的实时键位以及“设置”中的账号外观也可直接选取组件。可分别修改页面、分类栏、模块列表、参数组、具体参数行、开关、滑块、输入框、菜单、文字和头像的布局、尺寸、字体、颜色、透明度、圆角、玻璃模糊、留白、可见性及层级。原有玻璃主题为默认样式。

先切换工具栏的“选择组件”为“浏览导航”，再选择配置范围、文件、分类、模块或参数组；切回选择模式进行外观编辑。浏览导航允许搜索、筛选和展开，但不会通过配置的保存按钮或游戏参数开关提交修改。双击可深入控件子层，图层面板可选择隐藏组件。

动态行按配置文件、模组、参数组、参数名称／键位 ID 识别，筛选、排序和切换模块不改变其身份。SlimefunHelper 和 Meteor 使用独立页面外观。编辑存为草稿，可撤销、重做、重置组件、重置页面，应用后持久保存；完整主题码支持导入导出。主题只包含外观，不包含游戏配置、账号凭据或桥接令牌。
